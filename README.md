One line, a voicemail greeting recorded by a cat:

> You've reached the cat. I'm asleep in the box it came in. Leave a message after the beep — I'll knock it off the table.

The judge's brief weighs five things, most important first: the line
reads as a voicemail greeting recorded by a cat and lands a laugh; the
joke comes from something specific to cats, not a generic joke with the
word cat dropped in; the cat has a clear voice and attitude of its own;
it works spoken aloud in the few seconds a caller waits, with the punch
arriving quickly; and the wording is fresh rather than a known pun.

The cat speaks for itself from the first words, in the first person,
unbothered and a little smug. The joke is cat-specific twice over: the
cat is asleep in the box the caller's order came in, the classic box,
and then the punchline turns the voicemail itself into the next victim
— the message left after the beep is going off the table like
everything else the cat has ever met. Spoken aloud it runs in one
breath and the punch lands on the last clause.

## How to run

```sh
python3 main.py
```

The program writes exactly that line, and nothing else, to
`entry.txt` in `$MAKEFUN_OUTPUT_DIR` (default `/output`) — 119
characters, inside the 1–120 character gate, a single line. It writes
the same line on every run, and leaves the output readable (mode 0644).
